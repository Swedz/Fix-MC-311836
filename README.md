# Fix MC-311836

[MC-311836](https://bugs.mojang.com/browse/MC/issues/MC-311836) is a vanilla Minecraft bug only present in 26.3, as it
was patched in a snapshot for 26.4. The bug causes mounts (specifically Minecarts, Happy Ghasts, and Nautiluses) to
sometimes play their sounds more than once while riding them. This causes the sound to become overlayed on top of itself
creating a strange distorted sound. This mod fixes this bug!
